# DOOR — проект «Сталь-Плюс» (входные двери, Липецк)

Репозиторий проекта завода входных дверей **ООО «Сталь-Плюс»** (Липецк).

## Структура

- **`tripl-doors/`** — основной проект: пайплайн подготовки контента (сбор SERP,
  анализ конкурентов, генерация ТЗ и текстов). См. `tripl-doors/CLAUDE.md`.
- **`stal-plus-design-system/`** — дизайн-система бренда: токены, компоненты
  (Button, Cover, FeatureCard, SectionHeading, StatTile), логотип.
- **`source-materials/`** — исходные материалы:
  - `sertifikaty-sootvetstviya-stal-plus.docx` — распознанный текст сертификатов
    соответствия (противопожарные двери ДПМ и др.);
  - `serp-extra-23.xlsx` — данные SERP.
