## ⚙️ Формат вставки на боевой сайт (тема Porto + Elementor + Popup Maker)
С витрин 03 и 04 каждая страница отдаётся ДВУМЯ HTML-файлами для вставки в HTML-виджеты Elementor
(спецификация — `methodology/style-landing-porto.md`):
- **`{slug}-hero.html`** — верхний блок (hero), вставить в виджет ДО каталога WooCommerce.
- **`{slug}-content.html`** — нижний блок (текст, таблицы, схемы, FAQ, контакты, О заводе + JSON-LD внутри
  блока), вставить ПОСЛЕ каталога. JSON-LD теперь внутри контент-блока, отдельный `.jsonld` не нужен.
Каталог между блоками выводит WooCommerce (не верстаем). Шапку/крошки/подвал не включаем (они в теме).
Шрифт Poppins (Porto грузит сам), CTA → `href="#svyaz"` (попап pum-9515), фото hero → `[cat_hero_image]`,
full-bleed для hero и серых секций, дата обновления — скрипт (текущий месяц − 2).
- **`{slug}.html`** — самодостаточная страница-превью (с шапкой/подвалом/крошками и сеткой-заглушкой) для
  приёмки/демонстрации; на боевой сайт идут два блока выше, не этот файл.
Все четыре витрины (01, 02, 03, 04) переведены в двухблочный формат Porto; у каждой есть `{slug}-hero.html`,
`{slug}-content.html` и превью `{slug}.html`. Прайс монтажа/доставки внедрён на всех (блок `.szp-price`).
