## Куда раскладывать на боевом сайте (WooCommerce) — порядок по решению оператора 2026-09-20
Порядок блоков: **Hero → витрина (сетка) → текст → остальное**.
- **Hero-банд** (H1 + оффер + цифры + CTA) — самый верх страницы.
- **Сетка карточек** — штатный вывод WooCommerce (реальные товары и цены; ничего не выдумано). Идёт СРАЗУ под hero.
- **Верхнее/нижнее описание категории (текст под сеткой):** паспорт-абзац «Сталь-Плюс — завод…» + «Коротко»
  + «Где купить» + «Из чего цена» + «Надёжность» (+таблица +Рис.2) + «Терморазрыв» (+Рис.1) +
  «Противопожарные двери» (+Рис.3) + «Доставка, замер, установка и гарантия».
- **В самом низу:** «Контакты», «Частые вопросы», «О заводе и материале».
- **JSON-LD** → в `<head>`. **Мета** → в поля SEO-плагина.
