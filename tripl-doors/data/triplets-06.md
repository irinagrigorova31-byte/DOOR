## 4. Незаменимый узел витрины 06
Локальный завод дверей в Липецке (ОКВЭД 25.12) + **усиленные стальные входные двери повышенной взломостойкости,
соответствие ГОСТ 31173-2016 (серт.3, реальный номер)** + честный разбор «что делает дверь взломостойкой» без
выдуманного класса + изготовление по размерам + свой замер/монтаж. Разведение с витриной 01 (общий вход) и 04
(противопожарные) состоятельно.

## 5. Пустоты (заявки на отстройку)
1. Честный определитель «что делает дверь бронированной» (сталь, рёбра, противосъём, замки) без выдуманного класса.
2. Завод-изготовитель + по размерам + свой монтаж (против перекупа с заявленным классом без документа).
3. Соответствие ГОСТ 31173-2016 с реальным номером серт. + машиночитаемый Offer/прайс.

## Governance (жёстко)
- **Класс взломостойкости числом НЕ заявлять** (нет документа ГОСТ Р 51072); «100% защита»/«абсолютная броня» — нельзя (ФЗ-38).
- Толщину стали/спеку брони числом не выдумывать → «на что смотреть» + карточка.
- Цена изделия — карточки WooCommerce; монтаж/доставка — прайс (`pricing-montage-delivery.md`, группа «Монтаж в готовый проём» + «Доставка»).
- Соответствие ГОСТ 31173-2016 — через номер серт.3 (verified); hasCertification = серт.3. «С 2005» — преемственность. NAP 398056.
- Пересечение с витриной 01 — мост 06↔01; ретро-правка 01 по решению оператора. Тире по правилу.
