# Triplets — витрина 11 «Гаражные ворота с калиткой» (2026-10-07)

SERP предоставлен (`serp-extra-128.xlsx`). Частотность по топу/Обзору ИИ/PAA + скилл + перенос из к.03/08. Чужие числа не берём.

## Ядро (калитка)
- K01 Калитка → встраивается в → створку ворот (вход без открытия тяжёлых створок).
- K02 Калитка → бывает → встроенная в створку или отдельная рядом (определитель по ширине проёма).
- K03 Встроенная калитка → требует → достаточной ширины створки (иначе отдельная калитка рядом). [SERP, без чужих мм]
- K04 Порог калитки → чем ниже → тем удобнее вход и меньше риск споткнуться; совсем без порога нельзя (задувает/подтекает).
- K05 Ворота с калиткой → делаются → утеплёнными или холодными (мост на 08 за глубиной утепления).
- K06 Ворота с калиткой → изготавливаются → по размерам проёма (калитка закладывается в чертёж по замеру).
- K07 Цена под ключ → из → ворот с калиткой + доставки + монтажа; изделие — карточки.

## Own-факты (завод)
- KO1 Распашные металлические ворота с калиткой → соответствуют → ГОСТ 31174-2017 (серт.2 № ССГБ RU.СП01.Н00698, «с калиткой и без»).
- KO2 Завод «Сталь-Плюс» (ОКВЭД 25.11) → делает → стальные распашные ворота с калиткой; ООО в ЕГРЮЛ (ОГРН 1194827000015).
- KO3 Завод → выполняет сам → замер, доставку, монтаж по Липецку; гарантия от изготовителя; с 2005 (преемственность).

## Точки отказа (SERP + перенос; KR1–KR4)
- KR1 Встроенная калитка в узком проёме → не помещается → отдельная калитка рядом (определитель на замере).
- KR2 Высокий порог калитки → неудобно переступать → невысокий порог с уплотнением (но не нулевой).
- KR3 Секционные с калиткой → зависят от привода/места/сервиса → распашным это не нужно (развилка → 03).
- KR4 Готовые «под стандарт» → калитку не поставить где удобно → по размерам, калитка в чертёж.
