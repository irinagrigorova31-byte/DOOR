## Ядро (термодверь / морозостойкая)
- T01 Терморазрыв → это → вставка с низкой теплопроводностью в полотне и коробке.
- T02 Терморазрыв → делит → металл двери на холодную и тёплую части (убирает мостик холода).
- T03 Дверь с терморазрывом → не промерзает и не потеет → зимой на входе с улицы (при верной конструкции и монтаже).
- T04 Терморазрыв → нужен → и в полотне, и в коробке (иначе мостик холода по коробке). [SERP-нюанс, отстройка]
- T05 Морозостойкая дверь → это → уличная стальная дверь с терморазрывом и утеплением.
- T06 Дверь с терморазрывом → отличается от обычной → тем, что обычная проводит холод насквозь (промерзает, конденсат).
- T07 Морозостойкая дверь → делается → по размерам проёма (нестандарт), от 2 суток.
- T08 Цена под ключ → складывается из → двери + доставки + монтажа; изделие — карточки.

## Own-факты (завод)
- TO1 Стальная дверь ДМ (в т.ч. с терморазрывом) → соответствует → ГОСТ 31173-2016 (серт.3 № ССГБ RU.СП01.Н00697).
- TO2 Завод «Сталь-Плюс» (ОКВЭД 25.12) → варит → двери с терморазрывом; ООО открыто в ЕГРЮЛ (ОГРН 1194827000015).
- TO3 Завод → выполняет сам → замер, доставку, монтаж по Липецку и области; гарантия от изготовителя.
- TO4 Отделка для улицы → порошковое напыление (влагостойкий МДФ в тепле). Производство с 2005 (преемственность).

## Точки отказа (SERP PAA «почему промерзает»; TR1–TR4)
- TR1 Терморазрыв только в полотне, коробка холодная → мостик холода по коробке → брать в полотне и коробке.
- TR2 Кривой монтаж / щель по притвору → продувание и конденсат → замер и монтаж бригадой завода.
- TR3 Тонкая дешёвая вставка → не держит мороз → смотреть конструкцию, а не слово «терморазрыв» в названии.
- TR4 Готовая «под стандарт» в проёме частного дома → щели → по размерам проёма.
