- Калитка встраивается в полотно/створку; вход без открытия всего полотна → экономия тепла, ресурса механизма, удобство, компактность (vs отдельная калитка рядом).

- **Порог калитки** — у секционных варианты по высоте (чужие числа 145/100/20 мм — НЕ брать); суть: низкий/плоский удобнее для прохода, снижает риск споткнуться. Prompt 3 «без порога». Честно: низкий, но не нулевой (задувает/подтекает) → наша отстройка.
- Ограничения встроенной калитки: нужна достаточная ширина ворот/створки (чужие числа 2125/920 мм — НЕ брать); иначе — отдельная калитка рядом. Это основа нашего определителя «встроенная vs отдельная».
