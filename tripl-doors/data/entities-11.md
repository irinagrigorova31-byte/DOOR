# Entities — витрина 11 «Гаражные ворота с калиткой» (2026-10-07)

Главная сущность — **гаражные ворота с калиткой** (металлические распашные со встроенной калиткой). Признак-центр = КАЛИТКА.

## Граф сущностей
- **Ворота с калиткой (ворота с дверью)** — ядро. Синонимы ЦА: со встроенной калиткой, с дверью, с проходной дверью.
- **Калитка** — узел-центр: встроенная в створку / отдельная рядом; порог (высокий/низкий); петли, замок, уплотнение.
- **Распашные металлические ворота** — наш тип (сварная конструкция, серт.2 ГОСТ 31174-2017 — «ворота с калиткой и без»).
- **Секционные / автоматические ворота с калиткой** — развилка (доминанта топа), НЕ наш Offer.
- **Утепление** — опция (мост → 08). Завод #org (ОКВЭД 25.11). Гео — Липецк (Q3490).

## Разведение сущностей (кластер ворот 03/08/11)
- 03 = тип (распашные vs секционные). 08 = распашные конфигурация. 11 = калитка. Пересечение — только компонент
  «калитка» (который в 03/08 упоминается вариантом) → 11 раскрывает калитку, 03/08 бриджат на 11.

## Незаменимые узлы (own)
- Серт.2 ГОСТ 31174-2017 (№ ССГБ RU.СП01.Н00698) — покрывает «ворота металлические с калиткой и без». hasCertification.
- Распашные стальные сварные с встроенной калиткой от завода (в топе доминируют секционные бренды) — пустая ниша.
- «Встроенная или отдельная калитка» + «порог честно» (низкий, не нулевой) — отстройка. По размерам; свой замер/монтаж; с 2005.

## НЕ выдумывать (governance, усилено SERP)
- Высоту порога в мм (чужие 145/100/20); мин. ширину ворот/калитки в мм (чужие 2125/920); толщину стали числом;
  цену числом (карточки); °C. Оснащение секционных (датчик/доводчик/ловитель) к нашим распашным не приписывать.
- Секционные/роллетные/автоматические — развилка, не Offer. «Без порога» абсолютом не обещать.
