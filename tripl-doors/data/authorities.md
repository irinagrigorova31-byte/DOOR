# Авторитетные первоисточники ниши (реестр для ON-SITE ссылок)

Реальные первоисточники, на которые ССЫЛАЮТСЯ свои страницы (on-site) под проверяемые
нормативные/статистические факты. Ведёт **niche-expert** (режим 2, реальным поиском — не выдумывать);
оператор может досеять известные первоисточники. Читают: `tz-writer` (кладёт в ТЗ факт → источник),
`copywriter` (ставит ссылку в теле), `schema-markup` (`citation`/`isBasedOn`), проверяет `gist-auditor`.

**Только для on-site.** Внешние размещения (off-site) authoritative-ссылки не несут (правило 3).

**Что сюда идёт:** регулятор · официальный реестр/база · текст закона/приказа · отраслевой стандарт
(ГОСТ/СП) · официальная статистика. **Что НЕ идёт:** блоги, агрегаторы, СМИ-пересказы, сайты
конкурентов, маркетплейсы.

Статус: `verified` — URL открыт и это действительно первоисточник; `to-check` — найден, но не сверен;
пустой URL — «нет данных», ссылку не ставить.

> **Проверка проведена niche-expert 2026-09-17** (WebFetch/WebSearch). Реестр датозависим: редакции
> ГОСТ и адреса реестров устаревают — сверять перед публикацией.
> **Аккуратно с агрегаторами:** `docs.cntd.ru` (Кодекс/Техэксперт) и `base.garant.ru` — НЕ первоисточники
> (это правовые агрегаторы), к тому же `docs.cntd.ru` при проверке уводит на авторизацию (`auth.kodeks.ru`,
> 302) → как публичная dofollow-ссылка не годится. Первоисточник по ГОСТ — только карточка Росстандарта
> `protect.gost.ru`.

## Гэпы к on-site-ссылкам (значимые нормы БЕЗ найденного первоисточника — назвать явно)

- **ГОСТ Р 51072-2005 (классы взломостойкости двери):** первоисточник Росстандарта прямым URL не
  найден 2026-09-17. Это дыра: факт «класс взломостойкости по ГОСТ Р 51072» подкрепить дофоллоу-ссылкой
  на первоисточник пока НЕЛЬЗЯ. Варианты для tz-writer: (а) искать карточку protect.gost.ru повторно;
  (б) переносить нормативную опору на verified ГОСТ 31173-2016; (в) давать факт без ссылки. Не подставлять
  агрегатор (cntd/garant) под видом первоисточника.
- **ГОСТ Р 52582 (замки для защитных конструкций — классы замков):** в режиме 1 скилл ссылался на этот
  номер по классу замка; первоисточник не проверялся → к on-site-ссылке НЕ готов, статус нет данных.
- **Число замков / «два замка»:** нормативная опора = ГОСТ Р 51072-2005 (см. выше) — тот же гэп URL.
