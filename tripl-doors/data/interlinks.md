# Кокон-карта (семантические силосы) + граф внутренних ссылок ON-SITE

Проектная карта внутренней перелинковки. **Ведёт `tz-writer`** (проекция на страницу — блок
ПЕРЕЛИНКОВКА каждого ТЗ). **Целостность проверяет `cluster-inspector`** (§5, против этой карты).
**Разводит `page-builder`** (из блоков ПЕРЕЛИНКОВКА, выведенных отсюда). Это не текст страницы — это
граф; заполняется по ходу проектирования ТЗ, при параллели дописывается (чужие коконы не перезаписывать).

## Что такое кокон
Кокон — тематический кластер страниц вокруг одной темы: **опорная (pillar)** держит общую теорию,
**дочерние** несут только меняющееся (цифры, ограничения, локальную специфику). Внутри кокона: дети
ссылаются на pillar, pillar — на детей, дети — на соседей по смыслу (sibling). Между коконами —
только явные **мосты** (по одной осмысленной связи), а не сплошная линковка всех со всеми.

## Правила
- **Один анкор = одна цель.** Разные анкоры на один URL — проверить, что это канонические имена, а
  не коммерческие ключи. Один анкор на разные URL — конфликт (cluster-inspector завернёт).
- Анкор = **каноническое имя сущности** из `data/entities.md`, не «купить X дёшево».
- Нет изолированных страниц: у каждой ≥1 входящая ссылка внутри кокона.
- Мост между коконами заявляется здесь явно; самодеятельный мост в тексте, которого нет в карте, —
  расхождение.

## Коконы

Проект однокластерный: одна целевая витрина = опорная страница. Отдельной серии дочерних страниц под
эту витрину НЕ создаём (охват — `input/about.md`; фасеты «в квартиру/в дом/зеркало/нестандарт» — навигация
внутри самой витрины, не отдельные URL). Поэтому вместо кокона — витрина + мосты на уже существующие
смежные категории/страницы сайта.

### Витрина (опорная) `/product-category/vhodnye-dveri/`
| Страница (URL) | Роль | Ссылки СЮДА (откуда · анкор) | Ссылки ОТСЮДА (куда · анкор) |
|---|---|---|---|
| /product-category/vhodnye-dveri/ | опорная (цель) | смежные категории · «входные двери в Липецке» | см. мосты ниже |

### Мосты (dofollow, анкор = каноническое имя сущности из `data/entities.md`)
| Из · страница | В · страница | Анкор | Зачем мост |
|---|---|---|---|
| витрина · H2-5 | /product-category/protivopozharnye-dveri/ (уточнить URL) | противопожарные двери | отстройка/незаменимый узел, отдельная категория (не квартирная дверь) |
| витрина · H2-4 | категория/фасет «двери с терморазрывом» (уточнить URL) | входные двери с терморазрывом | точка отказа «кому нужен терморазрыв» |
| витрина · E-E-A-T | /o-nas/ | завод входных дверей в Липецке | доверие/E-E-A-T, производство и стаж |

> URL смежных категорий уточнить по карте сайта на этапе page-builder (движок WooCommerce). Один анкор =
> одна цель; обратные ссылки со смежных категорий на витрину — анкор «входные двери в Липецке».
