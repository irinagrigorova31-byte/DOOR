# Domain-inventory — кластер 07 «Внутренние ставни на окна»
> Шаг 1.5. SERP не предоставлен → реверс cache-less, матрица по промптам + скилл + own. Маркетплейсы — placement.

## Конкуренты (реверс-контекст, без фетча, гипотезы ниши)
Сегмент внутренних (интерьерных) ставень: мастерские по деревянным/МДФ ставням, жалюзийные (louvered) ставни,
столярные производства, частично — поставщики плантационных ставень (plantation shutters). Иной материал/эстетика,
чем металлоизделия. Placement: Avito, Ozon, Wildberries, Леруа Мерлен, маркетплейсы интерьера.

## Наш домен
Новая категория. Профиль завода — металлоизделия по размерам + свой замер/монтаж. Для внутренних ставень
материал/тип не фиксируем без данных оператора; позиционируем «по размерам окна + замер/монтаж», тип и материал —
в карточке / на замере.

## Разведение с витриной 05
05 — наружные антивандальные стальные (взлом). 07 — внутренние (затемнение/приватность/интерьер). Разные монтаж,
назначение, ЦА. Мост 07↔05 (развод интентов), чтобы посетитель с «защитой» ушёл на 05, а с «затемнением» остался на 07.

## Разрыв / маршрут
Без SERP ранжирование не измеряем. Маршрут on-site: своя витрина под затемнение/интерьер/по размерам +
определитель типов + прайс (доставка числом, монтаж после замера).

## Открытые вопросы оператору
- Материал/тип внутренних ставень (металл/дерево/МДФ/жалюзи)?
- Прайс монтажа внутренних ставень (в прайсе нет) — пока «после замера».
