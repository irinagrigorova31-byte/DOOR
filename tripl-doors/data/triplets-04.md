## 4. Незаменимый узел витрины 04
Локальный завод дверей в Липепке (ОКВЭД 25.12) + **собственные противопожарные двери ДПМ с пределом EI60/S15,
подтверждённые реальными сертификатами (обязательный ЕАЭС RU C-RU.НЕ25.В.00065/25 по ТР ЕАЭС 043/2017 +
добровольный по ГОСТ Р 57327-2016)** + типоряд одно/двупольных с остеклением и без + изготовление по размерам
проёма (800–2200 × 1900–3250) + свой замер/монтаж по Липецку + честный определитель «какой предел и тип под задачу».
Не переносится на витрины 01–03 (обычные двери/ворота). Это сильнейший дифференциатор клиента.

## 5. Пустоты (заявки на отстройку, у топа нет)
1. Реальные номера сертификатов (ЕАЭС + ГОСТ) в видимом тексте и в hasCertification JSON-LD.
2. Завод в Липецке + изготовление ДПМ по размерам проёма + свой монтаж.
3. Определитель тип/предел (EI 30 vs EI 60; одно/двупольные; остекление) под задачу — у конкурентов общая статья без привязки к своему сертифицированному ряду.

## Governance (жёстко)
- Цены/монтаж числом НЕ публикуем; спека без выдуманных чисел (кроме verified из серт.: полотно ≥64 мм, размеры 800–2200 × 1900–3250, EI60/S15, 10 лет).
- **EI60 — единственный verified предел.** EI30/EI90/EI120 как СВОЙ продукт числом НЕ заявлять (только справочная классификация из Обзора ИИ).
- Марку наполнителя/стекла у себя не выдумывать сверх verified («ПромГласс EIW60» — только для остеклённых -О, из серт.5).
- «С 2005» — преемственность, не привязывать к ОГРН. Реквизиты/NAP — 398056 (НЕ 398026 из бланка серт.).
- EI — латиница, без гомоглифов. Правило тире (`methodology/dash-rule-ru.md`) — применяется к тексту этой витрины.
