# Entities — витрина 09 «Входные группы» (2026-10-02)

Главная сущность витрины — **входная группа** (металлоконструкция для входа в частный дом). Это НЕ дверь
(витрины 01/02) и не отдельный козырёк: это композитное изделие из нескольких стальных частей.

## Граф сущностей
- **Входная группа** — ядро. Синонимы ЦА: «вход в дом», «входная группа под ключ», «крыльцо с козырьком и дверью».
  Wikidata Q прямого точного соответствия нет (не выдумывать Q) → без sameAs на узел сущности.
- **Компоненты (части группы):**
  · Входная дверь (стальная; в составе группы — наша дверь по ГОСТ 31173-2016, серт.3). Сущность-мост к 01/02.
  · Козырёк / навес над входом.
  · Крыльцо / ступени (стальная площадка со ступенями).
  · Ограждение / перила.
  · Обрамление проёма (облицовка, откосы).
- **Завод-производитель** — ООО «Сталь-Плюс» (#org из company.md), ОКВЭД 25.11 (металлоконструкции) — профильно
  для входной группы как сварной стальной конструкции.
- **Гео** — Липецк (Q3490), область; выезд по РФ.

## Разведение сущностей (анти-каннибализация)
- 02 «двери для дома» = сущность «уличная входная дверь» (деталь). 09 = сущность «входная группа» (ансамбль
  дверь + козырёк + крыльцо + ограждение). Пересечение только в компоненте «дверь» → разводим мостом.
- 01 «входные двери» = общий каталог дверей (квартира). Мост 09 → 01.

## Незаменимые узлы (own)
- Завод в Липецке, ОКВЭД 25.11, ЕГРЮЛ (ОГРН 1194827000015) — доказуемость «завод, а не перекуп».
- По индивидуальным размерам входа; свой замер/доставка/монтаж; гарантия от изготовителя; с 2005 (преемственность).
- Дверь в составе группы соответствует ГОСТ 31173-2016 (серт.3) — честный факт о компоненте, НЕ сертификат на группу.

## НЕ выдумывать
- Сертификат/класс/ГОСТ на входную группу как конструкцию (нет документа) → hasCertification НЕ ставим.
- Размеры козырька/крыльца, число/высоту ступеней, толщину стали, материал кровли числом/маркой — «на замере».
- Цену группы числом в тексте (только карточки WooCommerce + расчёт после замера).
