- **Дата снятия:** в именах файлов даты нет («21»/«22» — номера выгрузок). Датировка **по mtime файлов: 2026-09-17** (pass-1 13:45, pass-2 14:44). Если фактическая дата снятия иная — уточнить у оператора; все числа матрицы датированы этим днём.

## Метод кластеризации
- Кластеры построены по пересечению блока **«Топ»** слитого массива (pass-1+pass-2, Google+Яндекс).
- **Итоговый K = 3 общих URL в топе по нормализованному домену+пути.** По одному хосту (без пути) при K=3 весь коммерческий массив + межкомнатные слипались в один ком (липецкие мультикатегорийные магазины ранжируются по любому коммерческому запросу). Переход на **домен+путь** (методический дефолт «нормализованный домен+путь») развёл межкомнатные («купить двери цены») в отдельный кластер и оставил инфо-интенты изолированными — K=3 по домену+пути дал устойчивую картину.
- Хосты нормализованы: `www.` срезан; **punycode ↔ кириллица сведены** (`xn---48-eddjhv7d.xn--p1ai` = `двери-48.рф`); ccTLD/поддомены — разные хосты. `двери-48.рф` и `двери48.рф` (без дефиса) — оставлены РАЗНЫМИ хостами (это разные домены).
- **Прим.: 6 коммерческих запросов сведены в ОДИН кластер (01)** сознательно — охват проекта — одна витрина, дробить их на 6 страниц = самосозданная каннибализация (III-7). Внутри кластера отмечены две гео-фасетки: Google без гео (нац. выдача Москва/Новосибирск) vs Яндекс-Липецк (приоритет по заданию).
