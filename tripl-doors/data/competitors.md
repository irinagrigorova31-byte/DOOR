## Как читать
- **гео** = липецкий (поддомен/локализация `lipetsk.` / `lipeck.` / `lipezk.` / `липецк.` / рег-код 48) vs иногородний/федеральный.
- **приоритет реверса**: Высокий (липецкий, реально ранжируется по Липецку) / Средний (федеральный завод-бренд, полезна структура/ассортимент) / Низкий (иногородний магазин, гео-размытие Google-нац., см. CLAUDE.md примечание оператора).
