# Triplets — витрина 09 «Входные группы» (2026-10-02)

SERP не предоставлен → частотность по промптам + скилл §16 + перенос из к.01/02. Числа конкурентов не берём.
Статусы: own = наш факт; R = точка отказа (сырьё отстройки).

## Ядро (входная группа в частный дом)
- R01 Входная группа → это → готовый вход из частей (дверь, козырёк/навес, крыльцо/ступени, ограждение).
- R02 Входная группа → делается → по размерам входа после замера (не типовая подгонка).
- R03 Входная группа → собирается → под ключ (эскиз + изготовление + монтаж одной бригадой завода).
- R04 Козырёк → укрывает → дверь; навес → укрывает → крыльцо (шире козырька).
- R05 Крыльцо и ступени → считаются → по высоте входа над землёй.
- R06 Ограждение (перила) → ставится → по краю площадки и вдоль ступеней (опора/безопасность).
- R07 Части группы → варятся → в одном стиле и по единым размерам (цельный вид, без подгонки на месте).
- R08 Цена под ключ → складывается из → состава группы + размеров + монтажа; изделие — карточки.

## Own-факты (завод)
- RO1 Завод «Сталь-Плюс» (ОКВЭД 25.11, металлоконструкции) → варит → входные группы из стали.
- RO2 ООО «Сталь-Плюс» (ОГРН 1194827000015) → открыто в → ЕГРЮЛ (доказуемость «завод, а не перекуп»).
- RO3 Завод → выполняет сам → замер, доставку, монтаж по Липецку и области; гарантия от изготовителя.
- RO4 Дверь в составе группы → соответствует → ГОСТ 31173-2016 (серт.3) — факт о компоненте, НЕ о группе.
- RO5 Производство → c 2005 (преемственность); цех 1000 м², 9 станков, 100–300 изделий/мес, ≈25 000 всего.

## Точки отказа (у перекупа 0 — чистая отстройка; RR1–RR4)
- RR1 Типовая входная группа → не подходит → частному дому (своя ширина/высота крыльца/число ступеней) → по размерам.
- RR2 Разные мастера по двери, козырьку и ступеням → рассинхрон стиля/сроков → одна бригада завода под ключ.
- RR3 Перекуп «дёшево» без замера/монтажа → крепление и сборку решает заказчик → завод даёт замер + монтаж.
- RR4 Нужна только дверь (крыльцо/козырёк есть) → входная группа избыточна → отдельная уличная дверь (мост → 02).

## Анти-каннибализация 02 ↔ 09 / 01 ↔ 09
- 02 = уличная дверь (деталь), центр терморазрыв/утепление/отделка. 09 = входная группа (ансамбль), центр состав/
  козырёк/крыльцо/под ключ/по размерам. Пересечение только в компоненте «дверь» → двусторонний мост (09→02, 02→09).
- 01 = общий каталог дверей (квартира) → мост 09 → 01.

## Незаменимый узел

по размерам, свой замер/изготовление/монтаж» — у перекупа без производства недоказуемо.
