## 4. Незаменимый узел витрины 05
Локальный завод металлоизделий в Липецке (ОКВЭД 25.11) + **стальные антивандальные ставни на окна по размерам
проёма** + защита от взлома/вандализма (сталь + надёжный запор, без выдуманного класса) + свой замер/монтаж по
Липецку + честная развилка «распашные стальные vs роллетные». Не переносится на витрины 01–04 (двери/ворота).

## 5. Пустоты (заявки на отстройку)
1. Завод-изготовитель + ставни по размерам окна + свой замер/монтаж (против перекупа).
2. Честная развилка «распашные стальные vs роллетные» — кому что.
3. Машиночитаемый Offer/прайс (доставка — числом из прайса; монтаж ставень — после замера, без числа).

## Governance (жёстко)
- Цена изделия — карточки WooCommerce; монтаж ставень числом нет в прайсе → «после замера»; доставка — из прайса (числом можно).
- **Класс взломостойкости / сертификат на ставни числом НЕ заявлять** (нет документа). hasCertification на витрине не ставить.
- Роллетные — развилка, не товар (до подтверждения оператора).
- Спека ставни без выдуманных чисел («на что смотреть» + карточка). «С 2005» — преемственность. NAP 398056.
- EI/огнестойкость и прочие чужие пределы не приписывать. Тире по `methodology/dash-rule-ru.md`.
