# Cluster-inspection — серия из пяти витрин (01 двери · 02 дом/улица · 03 ворота · 04 противопожарные · 05 ставни) (шаг 7)

> Инспектор: cluster-inspector, 2026-10-02. SERP по 05 не предоставлен. Вход: `drafts/page-05.md`, `data/tz/tz-05.md`,
> `data/entities-05.md`, `data/triplets-05.md`, витрины 01–04.

## 1. Тест симметрии (III-7)
Витрина 05 (ставни на окна) — отдельный продукт, не пересекается с дверями (01/02), воротами (03),
противопожарными (04). Иной проём (окно), иной интент. Каннибализации нет. Дублирующим массивом серия не является.

## 2. Обязательное ядро vs дублирование (GIST)
Совпадающие блоки (состав цены, доставка/замер/монтаж/гарантия, контакты/NAP, о заводе, FAQ про гарантию) —
коммерческое ядро Яндекса, резать запрещено. Формулировки адаптированы под ставни (окно, запор, анкеры, рама).

## 3. Дифференцирующие блоки — уникальны
Профиль 05 (распашные стальные vs роллетные, что делает антивандальными, по размерам окна, крепление анкерами) не
пересекается с дифференциаторами 01–04. Самосозданного конфликтного радиуса нет.

## 4. Governance-ось (честность, критично)
- Продукт — стальные ставни; факт «делаем ставни» заявлен оператором. Сертификата/ГОСТ/класса на ставни НЕТ →
  числом не заявлено, **hasCertification на витрине отсутствует** (проверено: в JSON-LD нет). ✓
- Роллетные поданы как честная развилка (H2 + таблица), НЕ как наш товар/Offer. ✓
- Цена изделия — карточки WooCommerce; монтаж ставень — «после замера» (в прайсе оператора ставень нет);
  доставка — числом из прайса. ✓
- Класс взломостойкости (как ГОСТ Р 51072 у дверей) на ставни не перенесён. ✓

## 5. Перелинковка / анкоры
05 → 01 «входные двери» (из «О заводе») + 05 → /o-nas. Конфликтов «один анкор → разные цели» нет.

## 6. NAP-консистентность
Все пять витрин → 398056, ул. Им. Баумана, стр. 307Е, оф. 1; тел.; ОГРН/ИНН. Совпадает.

## ВЕРДИКТ
**Архитектура серии из 5 витрин состоятельна.** Каннибализации нет. Возврат в tz-writer не требуется.
**Открытые вопросы оператору (не блокируют):** делаем ли роллетные (развилка/ассортимент); сертификат/класс на ставни;
прайс монтажа ставень. До ответов — честное позиционирование без выдуманных чисел.
