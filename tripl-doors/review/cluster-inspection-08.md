## 2. Анти-каннибализация 03 ↔ 08 (КРИТИЧНО — один продукт, тест III-7)
Риск: 03 `/garazhnye-vorota/` уже посвящена металлическим **распашным** воротам. 08
`/vorota-garazhnye-raspashnye/` рискует стать её дублем.

**Разрешение (разные интент и центр):**
- **03 = пилляр/развилка типов** — отвечает на «какой тип гаражных ворот» (распашные vs секционные). Центр: Рис.1
  дерево «распашные vs секционные», Рис.2 устройство ворот с калиткой, таблица «распашные и секционные — разница».
- **08 = профиль распашных** — покупатель тип уже выбрал, ищет конфигурацию/цену/утепление/размеры. Центр: Рис.1
  **определитель вариантов распашных** (створки/калитка/утепление), Рис.2 **разрез утеплённого полотна**, таблица
  «варианты распашных ворот». Сравнение распашные/секционные сведено к одному короткому H2-мосту → 03 (не центр,
  без дублирования таблицы 03).
- **H2-карты не пересекаются по центру:** 03 — «распашные или секционные / калитка и утепление / по размерам»;
  08 — «варианты распашных / утеплённые или холодные / по размерам / цена под ключ / (мост) секционные».
  Общие служебные H2 (где купить, доставка/замер/гарантия) есть у всех витрин серии — это NAP/услуги, не расфокус.
- **Двусторонний мост:** 08 → 03 анкор «гаражные ворота» (развилка типов); 03 → 08 анкор «распашные гаражные
  ворота» (добавлен в текст 03: content + оба превью). Симметрия есть.

Вывод: каннибализации нет — 03 ловит интент выбора типа, 08 ловит интент «распашные, какие и почём». Один продукт
подан двумя непересекающимися углами с мостами. ✓
