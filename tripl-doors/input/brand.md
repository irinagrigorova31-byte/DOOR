с витрины пиксель-в-пиксель; шкала типографики/отступов/радиусов снята со скриншотов (приближение).

## Шрифты
- Заголовочный: **PT Sans** (плейсхолдер-замена оригинала; грузится с Google Fonts) — 700
- Текстовый: **PT Sans** 400 (одно семейство `sans` несёт всё)
- Моно: нет
- Стек: `"PT Sans", "Segoe UI", system-ui, -apple-system, Roboto, Arial, sans-serif`
- Шкала: display 56/60 700 (только hero-цифры, blue); h1 34/40 700; h2 22/28 700 UPPERCASE blue +0.06em;
  h3 19/26 700; body 16/26 400; small 14/20; label 13/16 700 UPPERCASE +0.08em; button 15/20 700 UPPERCASE +0.04em.

## Логотип и бренд-ассеты
- Путь к логотипу: `assets/brand/stal-plus-lockup.png` (кроп со скриншота витрины — референс, не продакшн-вектор).
  Марка: металлический 3D-куб «M» над словом «СТАЛЬ-ПЛЮС», на navy-фоне. До получения SVG набирать имя `sans` 700.
- Использование в обложке: `референс` (палитра/настроение; логотип-кроп в кадр не впечатывать пиксель-в-пиксель — он низкого качества).
- (Только СВОЙ бренд-логотип. Чужие бренды/логотипы конкурентов — запрещены.)

## Форма / отступы / тени
- Углы КВАДРАТНЫЕ: `radius-square` = 0 — дефолт для кнопок, карточек, плиток товара (реальная бренд-черта, не смягчать).
  `radius-pill` (999px) только для поля поиска; `radius-full` — круглые соц-чипы/аватары.
- Отступы по 4px: space-1…space-10; база `space-4`=16px; ритм между секциями `space-10`=64px; гэп заголовок→контент `space-8`=48px.
- Тени: `shadow-card` 0 1px 3px rgba(16,45,80,.08) в покое; `shadow-raised` 0 8px 24px rgba(16,45,80,.12) для меню/дропдаунов.
- Тема одна — «Brand» (светлая). Тёмный подвал — это surface внутри светлой темы, НЕ вторая тема. Dark-режима нет.

## Иконки
- Тонкие одноштриховые лайн-иконки (~1.6px) в blue (доставка, ценник, гарнитура, телефон) + сплошные соц-глифы
  (VK, Telegram, WhatsApp) в круглых чипах. Реальных ассетов нет — превью рисуют inline-SVG заглушки.

## Тон / характер
Промышленный, доверие-первым. Русский язык, короткие уверенные утверждения («Доставим и установим», «Цены от
производителя»), формально-нейтральное «вы», без сленга и эмодзи. Сначала конкретное обещание (доставка,
собственное производство, гарантия 12 мес.), затем поддержка доверия. Заголовки секций — CAPS. Цифры — самое
громкое на странице: крупная цифра + тихая подпись («120+ / ТЫСЯЧ ИЗДЕЛИЙ», «1.5мм / ТОЛЩИНА МЕТАЛЛА»),
а не предложением. Глубокий navy в шапке, единственный яркий azure-акцент, near-black CTA, светло-серые секции —
фотографии товара несут страницу.
