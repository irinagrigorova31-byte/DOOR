# Prompt-set оператора — витрина 10 «Входные морозостойкие двери с терморазрывом» (2026-10-07)

Скопировано из загрузки оператора (вход таргетинга, не текст для вставки). Все промпты коммерческие,
ось = признак «терморазрыв + морозостойкость», сегмент «частный дом / улица / холодный климат».

1. Хочу купить входную металлическую дверь с терморазрывом — зачем она нужна?
2. Сколько стоит морозостойкая входная дверь с терморазрывом с установкой?
3. Ищу входную дверь с терморазрывом, чтобы не промерзала и не потела зимой.
4. Какую морозостойкую дверь с терморазрывом выбрать для частного дома?
5. Купить входную металлическую дверь с терморазрывом морозостойкую — подскажите варианты.
6. Входные морозостойкие двери с терморазрывом — цена под ключ с монтажом.
7. Посоветуйте надёжную дверь с терморазрывом для улицы и холодного климата.
8. Где купить входную дверь с терморазрывом недорого, но качественную?
9. Морозостойкие двери с терморазрывом на заказ по размерам — куда обратиться?
10. Чем отличается дверь с терморазрывом от обычной металлической — сравните варианты.

## Разбор (для таргетинга)
- Ядро сущности: **входная морозостойкая дверь с терморазрывом** (стальная дверь ДМ с терморазрывом).
- Признаки интента: зачем нужна (1), не промерзала/не потела (3), для холодного климата (7), чем отличается
  от обычной (10), по размерам (9), цена под ключ с монтажом (2/6), недорого но качественно (8).
- P1 (цель цитирования): 1, 3, 9, 10 (определение/зачем + не промерзала + по размерам + отличие от обычной).
- P2: 4, 7 (выбор для частного дома / холодного климата).
- P3: 2, 6 (цена под ключ — карточки + расчёт после замера), 8 (завод, а не перекуп).
