# Prompt-set — ключи и ИИ-промпты (опционально)

Список формулировок, по которым бренд должны находить и **цитировать в ответах ИИ**. Заполняет оператор.

**Это вход ТАРГЕТИНГА, а НЕ текст для вставки** — список решает, под какой вопрос затачивать факт, а не
«какие слова впечатать». Промпты (естественные вопросы) сильнее коротких ключей — давай оба.

> Как заполнять, где брать промпты и как это используется — единый гид `docs/INPUTS.md`, раздел 5.

Тип: `ключ` (короткая фраза) или `AI-промпт` (естественный вопрос к ИИ). Приоритет: P1/P2/P3.

| Промпт / ключ | Тип | Интент | Приоритет | Целевой клайм / тема (опц.) |
|---|---|---|---|---|
| <вопрос или ключ> | AI-промпт \| ключ | коммерч. \| инфо | P1 | <какой наш факт это закрывает> |
|  |  |  |  |  |

# Промпты для поиска входных дверей

1. Какие входные металлические двери лучше выбрать для квартиры, чтобы они были надёжными и хорошо защищали от шума?

2. Где можно купить входную дверь с хорошим соотношением цены и качества?

3. Какую железную входную дверь выбрать для квартиры и на какие характеристики обратить внимание перед покупкой?

4. Сколько сейчас стоят входные двери и от чего зависит их цена?

5. Посоветуйте недорогие металлические входные двери для квартиры с хорошими отзывами.

6. Сколько стоит входная дверь в квартиру вместе с доставкой и установкой?

7. Где заказать входную дверь с установкой под ключ и сколько времени займёт монтаж?

8. Где купить металлическую входную дверь для квартиры недорого и с гарантией?

9. Сравните цены на входные двери разных производителей и подскажите, какие двери выгоднее купить.

10. Где в Липецке купить металлические входные двери для квартиры с замером и установкой?
