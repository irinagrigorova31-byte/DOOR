# Prompt-set — ключи и ИИ-промпты (опционально)

Список формулировок, по которым бренд должны находить и **цитировать в ответах ИИ**. Заполняет оператор.

**Это вход ТАРГЕТИНГА, а НЕ текст для вставки** — список решает, под какой вопрос затачивать факт, а не«какие слова впечатать».
Промпты(естественные вопросы) сильнее коротких ключей — давай оба.

>
> Как заполнять, где брать промпты и как это используется — единый гид `docs/INPUTS.md`, раздел 5.
>

Тип: `ключ` (короткая фраза) или `AI-промпт` (естественный вопрос к ИИ). Приоритет: P1/P2/P3.


| Промпт / ключ              | Тип          | Интент | Приоритет | Целевой клайм / тема (опц.) |
|--------------------------------------|-----------------|--------------|--------------------|------------------------------------------------|
| <вопрос или ключ> | AI-промпт | ключ     | коммерч.    | инфо                                       |
|                                 |            |         |               |                                           |

1. Хочу купить бронированную входную дверь — чем она отличается от обычной металлической?
2. Сколько стоит бронированная дверь с установкой под ключ?
3. Ищу надёжную бронированную входную дверь для квартиры
4. Какую бронированную дверь выбрать для защиты от взлома?
5. Купить бронированную дверь с доставкой и монтажом — подскажите варианты
6. Бронированные входные двери — цена под ключ с установкой
7. Посоветуйте бронированную дверь с хорошим классом взломостойкости
8. Где купить бронированную входную дверь недорого, нокачественную?
