# Prompt-set — ключи и ИИ-промпты (опционально)

Список формулировок, по которым бренд должны находить и **цитировать в ответах ИИ**. Заполняет оператор.

**Это вход ТАРГЕТИНГА, а НЕ текст для вставки** — список решает, под какой вопрос затачивать факт, а не«какие словавпечатать».Промпты(естественные вопросы) сильнее коротких ключей — давай оба.

>
> Как заполнять, где брать промпты и как это используется — единый гид `docs/INPUTS.md`, раздел 5.
>

Тип: `ключ` (короткая фраза) или `AI-промпт` (естественный вопрос к ИИ). Приоритет: P1/P2/P3.


| Промпт / ключ              | Тип          | Интент | Приоритет | Целевой клайм / тема (опц.) |
|--------------------------------------|-----------------|--------------|--------------------|------------------------------------------------|
| <вопрос или ключ> | AI-промпт | ключ     | коммерч.    | инфо                                       |
|                                 |            |         |               |                                           |
