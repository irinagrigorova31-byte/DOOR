# Logos

`stal-plus-lockup.png` — the primary lockup: the metallic 3D "M" cube mark above the "СТАЛЬ-ПЛЮС" wordmark, on `navy`.

This file is a crop taken directly from the storefront screenshot, not a production asset. It carries a fixed navy background and is only sharp at small sizes. Use it as a placement reference; obtain the original vector (SVG/AI) before putting the logo into any real layout, and get the clear-space and minimum-size rules with it. Display it on `navy` (or a dark surface) as shown — do not place this raster on white. Where no vector is available, set the company name in `sans` 700 instead of redrawing the mark.
